# Downloads do Lumen Desktop

As [releases publicadas no GitHub](https://github.com/natatgh/screen-share-p2p/releases) oferecem o instalador para Windows 11 e o ZIP standalone. Confira a versão e o SHA-256 do ZIP antes de usar. Releases em rascunho são destinadas a testes do mantenedor.

**Assinatura de código:** as releases atuais não têm assinatura Authenticode e podem ser bloqueadas pelo Smart App Control do Windows. Nenhum serviço de assinatura está configurado. Consulte a [Code signing policy](code-signing-policy.md) antes de baixar.

O site para espectadores continua disponível em [screen-share-p2p.vercel.app](https://screen-share-p2p.vercel.app), sem instalação.
